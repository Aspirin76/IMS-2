1. 系統環境資訊

項目 內容

3. 如何登入資料庫

方法一：使用 PowerShell（建議）

開啟 PowerShell，貼上這行：

& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -h localhost -U postgres -d ailearn

畫面會出現 Password for user postgres:，輸入密碼時畫面不會顯示任何字元（連 * 都沒有），這是正常的安全設計，直接打完按 Enter 即可。

登入成功會看到提示符號：

ailearn=#

方法二：先開資料庫、再切換

& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres

登入後在 postgres=# 輸入：

\c ailearn

方法三：使用 pgAdmin（圖形介面）

  1. 開啟 C:\Program Files\PostgreSQL\18\pgAdmin 4\runtime\pgAdmin4.exe
  2. 左側展開 Servers → 點 PostgreSQL 18
  3. 輸入密碼 → 勾選 Save password（下次就不用再打）
  4. 展開 Databases → 就會看到 ailearn

方法四：暫時加入 PATH（一勞永逸）

只對「目前這個視窗」有效：

$env:Path += ";C:\Program Files\PostgreSQL\18\bin"
psql -h localhost -U postgres -d ailearn

永久加入（改使用者環境變數，需重開視窗才生效）：

[Environment]::SetEnvironmentVariable(
    "Path",
    [Environment]::GetEnvironmentVariable("Path","User") + ";C:\Program Files\PostgreSQL\18\bin",
    "User"
)

4. psql 常用指令速查

以下指令都在 ailearn=# 提示符號下輸入。結尾要加分號 ;，只有 \ 開頭的 meta 指令不用。

資料庫操作

指令 說明
\l 列出所有資料庫
\c ailearn 切換到 ailearn 資料庫
\conninfo 顯示目前連線資訊
\q 離開 psql

資料表操作

指令 說明
\dt 列出目前資料庫的資料表
\dt+ 列出資料表（含大小）
\d 資料表名 顯示資料表結構
\d+ 資料表名 顯示結構（含儲存資訊、註解）
\dn 列出 schema
\dv 列出 view
\di 列出索引
\df 列出函式

使用者與權限

指令 說明
\du 列出所有使用者與角色
\du+ 同上（含說明）

其他好用指令

指令 說明
\h 查詢 SQL 語法說明（例：\h CREATE TABLE）
\? 列出所有 psql 指令
\x 切換「展開顯示」模式（欄位多時好用）
\timing 顯示每條 SQL 的執行時間
\e 用編輯器寫 SQL
\i 檔案路徑 執行外部 SQL 檔
\o 檔案路徑 把查詢結果輸出到檔案
\q 離開

5. 常用 SQL 範例

建立資料庫

CREATE DATABASE ailearn;

刪除資料庫（小心！）

DROP DATABASE ailearn;

建立資料表

CREATE TABLE products (
    id          SERIAL PRIMARY KEY,
    name        VARCHAR(100) NOT NULL,
    category    VARCHAR(50),
    unit        VARCHAR(20),
    price       NUMERIC(10,2) DEFAULT 0,
    stock_qty   INTEGER DEFAULT 0,
    safety_qty  INTEGER DEFAULT 10,
    created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

新增資料

INSERT INTO products (name, category, unit, price, stock_qty)
VALUES ('螺絲 M8', '五金', '個', 3.50, 1200);

查詢資料

SELECT * FROM products;
SELECT name, stock_qty FROM products WHERE stock_qty < safety_qty;

更新資料

UPDATE products SET stock_qty = stock_qty + 100 WHERE id = 1;

刪除資料

DELETE FROM products WHERE id = 1;

查看資料庫大小

SELECT pg_size_pretty(pg_database_size('ailearn'));

查看資料表大小

SELECT relname,
       pg_size_pretty(pg_total_relation_size(relid)) AS total_size
FROM pg_catalog.pg_statio_user_tables
ORDER BY pg_total_relation_size(relid) DESC;

6. 建立專案用的資料表

以下是「資料庫存管理系統」建議的基礎結構，可存成 schema.sql 後執行。

-- 1. 商品主檔
CREATE TABLE products (
    id          SERIAL PRIMARY KEY,
    sku         VARCHAR(50) UNIQUE NOT NULL,
    name        VARCHAR(100) NOT NULL,
    category    VARCHAR(50),
    unit        VARCHAR(20) DEFAULT '個',
    price       NUMERIC(10,2) DEFAULT 0,
    safety_qty  INTEGER DEFAULT 10,
    is_active   BOOLEAN DEFAULT TRUE,
    created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. 庫存現量
CREATE TABLE stock (
    product_id  INTEGER PRIMARY KEY REFERENCES products(id) ON DELETE CASCADE,
    qty         INTEGER NOT NULL DEFAULT 0,
    updated_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 3. 入出庫異動紀錄
CREATE TABLE stock_movements (
    id          SERIAL PRIMARY KEY,
    product_id  INTEGER NOT NULL REFERENCES products(id),
    move_type   VARCHAR(10) NOT NULL CHECK (move_type IN ('IN','OUT','ADJUST')),
    qty         INTEGER NOT NULL,
    note        TEXT,
    created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 4. 常用索引
CREATE INDEX idx_movements_product ON stock_movements(product_id);
CREATE INDEX idx_movements_date    ON stock_movements(created_at);
CREATE INDEX idx_products_category ON products(category);

執行方式（在 PowerShell）：

& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -h localhost -U postgres -d ailearn -f "schema.sql"

7. 資料備份與還原

備份單一資料庫

& "C:\Program Files\PostgreSQL\18\bin\pg_dump.exe" -h localhost -U postgres -d ailearn -F c -f "C:\backup\ailearn_20261021.backup"

參數說明：

  • -F c：custom 格式（可壓縮、可選擇性還原，建議用這個）
  • -F p：純 SQL 文字檔（可用記事本看，但檔案較大）
  • -f：輸出檔名

還原資料庫

& "C:\Program Files\PostgreSQL\18\bin\pg_restore.exe" -h localhost -U postgres -d ailearn -c "C:\backup\ailearn_20261021.backup"
  • -c：還原前先清空既有的物件

備份全部資料庫（含角色）

& "C:\Program Files\PostgreSQL\18\bin\pg_dumpall.exe" -h localhost -U postgres -f "C:\backup\all_20261021.sql"

定期自動備份（工作排程器）

可建立一個 backup.bat：

@echo off
set PGPASSWORD=你的密碼
set BK=C:\backup
if not exist "%BK%" mkdir "%BK%"
"C:\Program Files\PostgreSQL\18\bin\pg_dump.exe" -h localhost -U postgres -d ailearn -F c -f "%BK%\ailearn_%date:~0,4%%date:~5,2%%date:~8,2%.backup"

再搭配 Windows「工作排程器」設定每天執行即可。

⚠️ 用 PGPASSWORD 環境變數是好用，但密碼會以明文存在 .bat 檔裡，請確認該資料夾權限。

9. 帳號與權限管理

建立專用使用者（建議給應用程式用）

CREATE USER ailearn_app WITH PASSWORD '強密碼';
GRANT CONNECT ON DATABASE ailearn TO ailearn_app;

還要切換到 ailearn 資料庫授權 schema：

\c ailearn
GRANT USAGE, CREATE ON SCHEMA public TO ailearn_app;
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO ailearn_app;
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO ailearn_app;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO ailearn_app;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON SEQUENCES TO ailearn_app;

📌 PostgreSQL 15 以後，public schema 預設不開放建立權限給所有人，所以 GRANT 這步不能省略。

修改密碼

建議用 \password（不會留下明文記錄）：

\password

它會要求輸入新密碼兩次，並自動做 SCRAM 雜湊。

或用 SQL（明碼會留在歷史檔，較不安全）：

ALTER USER postgres WITH PASSWORD '新密碼';

刪除使用者

DROP USER ailearn_app;

查看使用者清單

SELECT rolname, rolsuper, rolcanlogin FROM pg_roles ORDER BY 1;

10. 疑難排解

問題 1：psql 不是內部或外部命令

原因： bin 目錄不在 PATH。

解法： 使用完整路徑，或參考 3. 方法四 永久加入 PATH。

問題 2：打密碼時畫面沒反應／打不出英數字

情況 A：其實有打進去，只是不顯示 密碼輸入本來就不會回顯任何字元，直接打完按 Enter 即可。

情況 B：輸入法卡在中文模式

  • 按一下 Shift 切回英文
  • 或 Ctrl + Space 關閉輸入法
  • 或 Win + Space 切換鍵盤配置

情況 C：全形模式 Shift + Space 切換全形／半形。全形數字 １２３ 看起來像英數，但打密碼一定失敗。

情況 D：完全打不進去

  1. 開記事本把密碼打好 → Ctrl+A、Ctrl+C
  2. 回到 psql 密碼提示 → 貼上（傳統主控台按滑鼠右鍵；Windows Terminal 按 Ctrl+Shift+V）
  3. 按 Enter

情況 E：鍵盤有問題 Win + R → 輸入 osk → 用螢幕小鍵盤點選。

問題 3：中文顯示變成亂碼

在 PowerShell 先執行：

chcp 65001

或設定成永久：

[Console]::OutputEncoding = [Text.Encoding]::UTF8

問題 4：password authentication failed

原因 解法
密碼打錯（最常見） 重新輸入，注意 0/O、1/l/I
全形字元 切回半形
密碼前後有空白 確認沒有多打的空白
帳號不存在 用 \du 確認使用者名稱
剛改完密碼 應用程式的設定檔也要同步更新

問題 5：忘記 postgres 密碼

需要系統管理員權限，步驟如下：

  1. 備份 C:\Program Files\PostgreSQL\18\data\pg_hba.conf
  2. 將 127.0.0.1/32 和 ::1/128 這兩行的 scram-sha-256 暫時改成 trust
  3. 重啟服務：Restart-Service postgresql-x64-18
  4. 免密碼登入：psql -h localhost -U postgres
  5. 改密碼：ALTER USER postgres WITH PASSWORD '新密碼';
  6. 把 pg_hba.conf 改回 scram-sha-256
  7. 再重啟服務一次

⚠️ 第 2～6 步期間資料庫是「無密碼可登入」的狀態，請勿在該狀態下讓電腦連外網。

問題 6：連不上資料庫（connection refused）

依序檢查：

# 1. 服務有沒有在跑
Get-Service postgresql-x64-18

# 2. 連接埠有沒有在聽
Get-NetTCPConnection -LocalPort 5432 -State Listen

# 3. 防火牆是否擋住
Get-NetFirewallRule | Where-Object DisplayName -like "*postgres*"

問題 7：permission denied for schema public

PostgreSQL 15 以後 public schema 預設不給建立權限，需手動授權（見第 9 節）。

12. 安全注意事項

  1. 密碼不要寫在程式碼或文件裡 — 使用 .env 或環境變數，並把 .env 加進 .gitignore。
  2. 不要用 postgres 超級使用者當應用程式的連線帳號 — 建立專用帳號（見第 9 節），只給必要權限。
  3. pgpass.conf 是明文 — 若使用免密碼設定，記得該檔案只有自己的 Windows 帳號可讀。
  4. listen_addresses = '*' — 目前設定成接受所有網路介面的連線。如果這台電腦不需要讓其他機器連線，建議改成 listen_addresses = 'localhost' 降低風險。
  5. 定期備份 — 至少每週一次 pg_dump，並把備份檔存到不同磁碟或雲端。
  6. 改完密碼要同步 — 資料庫、.env、pgAdmin 三處都要更新，否則會出現登入失敗。
